# CyberSafe Awareness Bot

## Overview
CyberSafe Awareness Bot is a C# desktop application built with WPF to promote cybersecurity awareness through interactive chatbot conversations.

## Features
- WPF graphical user interface.
- Voice greeting on application startup.
- Cybersecurity advice on passwords, phishing, scams, and online privacy.
- Randomised responses and conversational follow-ups.
- User memory and recall.
- Sentiment detection for worried, curious, and frustrated users.
- Input validation and error handling.

## Technologies
- C#
- .NET 9
- WPF and XAML
- GitHub Actions for Continuous Integration (CI)

## Project Assets
- `Audio/greeting.wav` — voice greeting.
- `CyberSafeASCII.png` — cybersecurity image.

## Getting Started
1. Install Visual Studio 2022 with the .NET desktop development workload and .NET 9 SDK.
2. Open `CyberSafeAwarenessBot2.sln`.
3. Restore dependencies, build the solution, and run the application.
